# 📋 نرم‌افزار سازنده فرم ورود و خروج پرسنل (یکتا)
### Yekta Personnel Attendance & In/Out Form Generator

یک نرم‌افزار جامع، مدرن و چندسکویی (Multi-Platform) مبتنی بر **Flutter** برای مدیریت پرسنل و تولید خودکار فرم‌های استاندارد ورود و خروج ماهانه بر اساس تقویم شمسی (جلالی) در قطع A4 افقی جهت چاپ دو رو (Duplex) و بایگانی آسان در زونکن.

---

## ✨ ویژگی‌های کلیدی (Key Features)

- 📅 **محاسبه هوشمند تقویم شمسی (جلالی):**
  - محاسبه خودکار تعداد روزهای ماه‌های شمسی (نیمه اول ۳۱ روزه، نیمه دوم ۳۰ روزه و اسفند ماه کبیسه/عادی).
  - تفکیک خودکار روزهای هفته و **برجسته‌سازی روزهای جمعه و تعطیلات رسمی**.
  - تنظیم پویا و آنی سال و ماه با نام‌های فارسی ماه‌ها.

- 📄 **تولید PDF استاندارد چاپ دو رو (Duplex A4 Landscape):**
  - **صفحه اول (روی برگه):** جدول نیمه اول ماه (روزهای ۱ الی ۱۶) برای ۳ نفر در هر صفحه.
  - **صفحه دوم (پشت برگه):** جدول نیمه دوم ماه (روزهای ۱۷ الی پایان ماه) برای همان ۳ نفر.
  - **حاشیه هوشمند پانچ زونکن:** در نظر گرفتن فاصله استاندارد پانچ (~۲۳ میلی‌متر) در لبه بالای صفحه رو و لبه پایین صفحه پشت جهت بایگانی بدون تداخل با محتوای جداول.
  - **جدول ماتریسی کامل:** شامل ردیف‌های تاریخ، ایام هفته و دو ردیف تفکیک‌شده‌ی «ورود» و «خروج» برای هر فرد در طول روزهای ماه.
  - تایپوگرافی استاندارد فارسی با قلم رسمی **وزیرمتن (Vazirmatn)** و امکان سوئیچ اعداد فارسی/انگلیسی.

- 👥 **مدیریت پیشرفته و چندلیستی پرسنل:**
  - تعریف و دسته‌بندی پرسنل در چندین لیست مستقل (مانند: شیفت روز، شیفت شب، کارگاه ۱، بخش اداری و...).
  - افزودن تکی پرسنل با تعیین سمت/عنوان شغلی.
  - **افزودن دسته‌جمعی (Bulk Import):** قابلیت کپی-پیست لیست نام‌ها به‌صورت خط‌به‌خط.
  - ویرایش، حذف، کپی کردن لیست‌ها و جستجوی سریع در نام‌ها و عناوین شغلی.

- 👁️ **پیش‌نمایش زنده و چاپ مستقیم:**
  - رندر بلادرنگ PDF در محیط برنامه قبل از چاپ.
  - امکان چاپ مستقیم به پرینتر سیستم یا ذخیره خروجی PDF با نام‌گذاری خودکار.

- 🎨 **رابط کاربری مدرن (Material 3 Expressive):**
  - پشتیبانی کامل از چینش راست‌به‌چپ (RTL).
  - پشتیبانی از حالت تیره (Dark Mode) و حالت روشن (Light Mode).
  - منوی ناوبری کناری روان و نشانگر وضعیت لحظه‌ای لیست و تعداد صفحات.

- 💾 **ذخیره‌سازی محلی خودکار:**
  - ذخیره دائمی کلیه لیست‌ها و تنظیمات در حافظه دستگاه (`shared_preferences`) بدون نیاز به اینترنت یا دیتابیس خارجی.

## 🚀 راهنمای نصب و اجرا (Getting Started)

### پیش‌نیازها
- نصب [Flutter SDK](https://docs.flutter.dev/get-started/install) (نسخه 3.13 یا بالاتر)
- یکی از محیط‌های توسعه: VS Code / Android Studio / IntelliJ IDEA
- فعال‌سازی ابزارهای بیلد پلتفرم هدف (مانند Visual Studio C++ برای Windows، یا ابزارهای Android/Web)

### راه‌اندازی و اجرای محلی

۱. مخزن پروژه را کلون یا باز کنید:
```bash
cd yekta_in_out_forms
```

۲. وابستگی‌های پروژه را دریافت کنید:
```bash
flutter pub get
```

۳. اجرای برنامه روی پلتفرم مورد نظر:

- **ویندوز (Desktop):**
  ```bash
  flutter run -d windows
  ```
- **تحت وب (Chrome):**
  ```bash
  flutter run -d chrome
  ```
- **اندروید / مک / لینوکس:**
  ```bash
  flutter run
  ```
